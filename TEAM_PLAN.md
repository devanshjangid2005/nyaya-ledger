# Team plan: who does what

Two people, working in parallel with almost no shared files.

- **Devansh (A): backend, AI, deploy, legal.** Needs the API key and the Render account. Owns `server/`, `scripts/`, `legal/`, `render.yaml`, `.env`.
- **Teammate (B): phone UI, testing on a real phone, submission materials.** Needs no API key. Owns `web/`, `docs/` and the slides, script and post.

Shared files (`README.md`, `package.json`, `shared/schema.ts`): tell the other person before editing.

## Rules

1. `main` auto-deploys to Render, so **don't push directly to `main`**. Use a branch per task (`a/real-model`, `b/ui-qa`), then open a PR, and the other person merges.
2. Before every PR: `npm run typecheck && npm test` (38 tests, no key needed). If you changed the UI: `npm run build && npm start`, then `npm run e2e -- http://localhost:8787`.
3. Never commit `.env` or API keys. Share the key privately, not in chat screenshots or the video.
4. Keep the Cline panel visible while you work, and save screenshots of good prompts and diffs to `docs/cline/`. The README, PPT and video need them.
